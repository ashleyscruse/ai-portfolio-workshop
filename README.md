# Build Your Portfolio with AI

A one-hour, hands-on workshop: participants organize a folder of context about
themselves (instructions, facts, projects, images), then use an AI coding assistant in
VS Code to build and publish a personal portfolio site on GitHub Pages.

The guide and prompt pack: https://ashleyscruse.github.io/ai-portfolio-workshop/

The starter folder participants copy: https://github.com/ashleyscruse/portfolio-starter

Setup

01

Get a GitHub account

If you don't have one, sign up at github.com. Pick a username you'd put on a résumé: it becomes your website address.

02

Copy the starter folder

Go to github.com/ashleyscruse/portfolio-starter and click Use this template, then Create a new repository.

Name it exactly your-username.github.io (with your real username) and choose Public. Click Create repository.

The name matters. your-username.github.io is what makes it a website.
03

Open it in VS Code

In VS Code, click the Accounts icon (bottom left) and sign in with GitHub.

Open the Command Palette (Ctrl+Shift+P, or Cmd+Shift+P on a Mac), type Git: Clone, choose Clone from GitHub, and pick your new repository. Save it somewhere you'll find it, then click Open.

04

Open the AI chat

Click the chat icon at the top of VS Code (or Ctrl+Alt+I / Cmd+Ctrl+I). Sign in to GitHub Copilot if asked; the free plan is enough for today.

In the chat box, set the mode dropdown to Agent. Agent mode can read and edit the files in your folder.

The folder

A good AI session starts before you type a prompt. This folder is the AI's memory: anything written here, you never have to explain again.

FileWhat it does
AGENTS.mdStanding instructions. The AI reads it first, every time: what the project is, where things are, the rules. Read it now; you can change any rule.
context/about-me.mdFacts about you. The AI is told to use only these, so it can't make things up.
context/style.mdHow the site should look and sound.
projects/One file per project, all the same shape. Yesterday's fine-tuning project is already started for you.
images/Your photos and charts, named for what they show.
05

Fill your folder (10 minutes)

a. Open context/about-me.md and fill in what you can. Blanks are fine; the AI will ask.

b. Open context/style.md and change anything you don't like.

c. Open projects/inspire-2026-fine-tuning.md and fill in your numbers from yesterday.

d. Drag a headshot or a screenshot into images/. Rename it for what it shows.

e. Got another project (a poster, a class project, a summer program)? Copy projects/_template.md, rename it, and fill it in.

This is a public website. No phone number, home address, student ID, or birthday.

Prompts

Copy each one into the chat, in order. Type # in the chat to attach a file by name. When the AI edits a file, read the change, then click Keep or Undo.

P1

Orient

Make the AI read before it writes. If its summary is wrong, your files are unclear: fix the file, not the chat.

Read AGENTS.md and every file in context/ and projects/. In five bullets, tell me what you know about me and what is still missing. Do not write any code yet.
P2

Interview

Let the AI fill your gaps by asking you. Your answers end up in a file, so they're saved for every future chat.

Interview me to fill in what is missing in context/about-me.md. Ask one question at a time and wait for my answer. After five questions, update the file and show me what changed.
P3

Plan

Planning is cheap; rebuilding is not. Push back on anything you don't like before it builds.

Plan a one-page portfolio site that follows context/style.md. List the sections in order and what goes in each, in plain words. Wait for my OK before building anything.
P4

Build

Then open it: right-click index.html, choose Reveal in File Explorer (or Reveal in Finder), and double-click it. Refresh the browser after every change.

Build the site from the plan: index.html and style.css at the top of the repo, following every rule in AGENTS.md. Use only facts from context/ and projects/ and images from images/. Where something is missing, leave a TODO comment and list the TODOs for me at the end.
P5

Feature a project

Attach just the file the job needs. Less context, better aim.

Make projects/inspire-2026-fine-tuning.md the featured project. Show the before and after accuracy and the speedup as a short row of numbers, and use the image listed in the file. Change nothing else on the page.
P6

Fix one thing

Describe what you see and where. You can also paste a screenshot into the chat. One fix per prompt.

On a phone-sized screen, [describe the problem and where it is]. Fix only that. Tell me which lines you changed.
P7

Remember

This is how the AI remembers between chats: decisions go in a file, not in your head.

Add the decisions we made today (colors, fonts, section order, anything else we settled) to the Decisions section of AGENTS.md, one line each with today's date.
P8

Check

Make the AI audit its own work against your rules before the world sees it.

Review index.html against AGENTS.md. List every rule it breaks and every fact on the page that is not backed by a file in context/ or projects/. Do not fix anything yet; just list them.

Context tips

Researchers and engineers who get great results from AI aren't better at typing prompts. They're better at organizing what the AI reads.

  1. Write it down once, point to it forever. If you've typed the same explanation twice, it belongs in a file.
  2. Same shape every time. Every project file has the same headings, so the AI (and you) can find anything.
  3. Name things for what they are. vista-scaling-chart.png tells the AI what it is. IMG_2041.png tells it nothing.
  4. Attach only what the job needs. More context isn't better; the right context is. Use # to point at one or two files.
  5. One job per chat. When the AI gets confused or starts going in circles, click + for a new chat. It rereads AGENTS.md and starts clean.
  6. Plan, then build. Ask for the plan first. Fixing a plan takes one sentence; fixing a website takes ten prompts.
  7. Make it ask, not guess. "Ask me" and "leave a TODO" are the two most useful phrases you have.
  8. Save decisions to a file. The chat forgets. AGENTS.md doesn't.
  9. Read before you Keep. You're the editor. If you can't explain a change, ask the AI to explain it or click Undo.
  10. Save points. When something works, commit it (below). If the next change breaks everything, you can go back.

Publish

01

Commit and push

Click the Source Control icon on the left (it looks like a branch). Type a message like First version of my site, click Commit, then Sync Changes. If it asks to stage all changes, click Yes.

02

Check Pages is on

On GitHub, open your repository, then Settings → Pages. Under Branch, choose main and / (root), then Save.

03

Visit your site

After a minute or two, go to https://your-username.github.io. Every time you commit and sync, it updates.

After today

Every time you finish something (a poster, a class project, a research summer), copy projects/_template.md, fill it in, and ask the AI to add it to your site. Five minutes, and your portfolio grows with you.
